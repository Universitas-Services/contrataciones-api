Notificación para el usuario (Tooltip visual al pasar el cursor si el botón está bloqueado):

Lógica del Sistema (Redacción técnica para tu documentación):
Comportamiento UI/UX: El botón de carga inicial se mantiene deshabilitado (disabled) por defecto. El frontend implementa un validador multi-paso que verifica de forma asíncrona la integridad de los datos en cada una de las secciones del formulario. Únicamente cuando el sistema confirma que todos los campos requeridos en la totalidad de los pasos poseen valores válidos, se retira el bloqueo del botón. Acción de Guardado (On-Click): Al hacer clic, el sistema ejecuta la persistencia de los datos en la base de datos y actualiza la variable de control estado_aspectos_generales_au_au al valor 'COMPLETADO' en el checklist interno, validando este bloque para la futura generación del Pliego.
